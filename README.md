## Aim
To study Static Application Security Testing (SAST) tools
and perform static security analysis using Bandit.

## Tool Used
Bandit - Python Security Analysis Tool.

## Procedure
1. Created a Python file named test.py.
2. Installed Bandit using pip.
3. Scanned the Python source code.
4. Identified potential security issues.

## Result
Bandit detected two potential security issues:
1. B605 - Starting a process with a shell.
2. B105 - Possible hardcoded password.

## Conclusion
Static Application Security Testing was performed
successfully using Bandit.
